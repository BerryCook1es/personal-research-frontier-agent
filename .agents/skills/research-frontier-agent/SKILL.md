# Personal Research Frontier Agent

This is the discoverable repository entrypoint, not a standalone script bundle.
Resolve the project root three directories above this skill directory. Before
running anything, read the complete [workflow](../../../SKILL.md) at that root.
Use its setup, configuration, evidence and feedback rules. If the linked workflow,
`scripts/frontier_tracker.py`, or `research_frontier_agent/` is missing, explain that
the full repository must be downloaded; do not guess another installation path.

Use the user's selected profile, projects and time window. Preserve existing API
configuration and do not display secrets. Generating a local report does not
authorize publishing it or setting up a recurring task.
