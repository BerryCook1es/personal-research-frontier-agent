## Research Description

博士研究主线聚焦科学文献与学术文本中的知识发现，尤其关注 paper-level / document-level scientific knowledge graph construction、科学实体/关系/主张/证据抽取，以及使用大语言模型完成长文档理解、信息抽取、知识图谱构建与事实性评估。方法邻域包括 RAG、GraphRAG、LLM Agent、多智能体与 LLM-as-a-Judge；生态背景包括文献计量、科学计量、科研评价与学术交流。
