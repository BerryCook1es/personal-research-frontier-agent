# Personal Research Frontier Agent · v0.1.0-beta

面向个人科研的前沿论文追踪公开测试版。基于
[frontier-tracker-LIS](https://github.com/shoucunren-tsy/frontier-tracker-LIS)
的 MIT 实现重构，保留 LICENSE 和 THIRD_PARTY_NOTICES.md。

## 功能

- 三个独立 Research Profile，可选多 Project Context。
- CrossRef / Semantic Scholar 发现，OpenAlex 摘要补全。
- 关键词 → 可选 Embedding → LLM 科研判断；翻译职责独立。
- 严格 JSON 校验、失败重试及响应留存、内容变化后的缓存失效。
- SQLite 增量状态、阅读反馈导出/导入。
- 个性化紫色星空页眉、中英双语 HTML，以及 Excel/App/Markdown 输出。
- PLOS ONE 跨源排除，仓库级 Skill、Windows/Linux CI。

## 安装

下载附件 ZIP 并解压，按照 README 安装 Python 依赖。公开配置中的所有 API Key
均为空；用户自行复制 config.example.json 为 config.local.json 并在本地填写。
没有附带私人 Key、数据库、论文结果、反馈或私人项目。
manifest 附件记录源 commit 与各文件 SHA-256。

## 测试与边界

发布工作流只有在 Windows/Linux、Python 3.9/3.12 测试全部成功后才创建此 Release。
自动化覆盖基础模式、多 Profile 隔离、增量、checkpoint、无 API 降级、数据库、
排除期刊、严格 Judge、缓存失效、失败响应及发布隔离。测试使用模拟服务，不消耗模型额度。

这是 Beta：独立 arXiv provider、自动兴趣学习、全局独立 Skill 插件分发尚未实现；
本地 BGE 模型未实机验证。来源可能缺少论文或摘要，LLM 分析需人工核实。
HTML/Excel/App 展示所有候选，阅读容量只限制 Markdown 笔记与阅读清单。
